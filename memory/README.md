# Memory

One note per day, named `YYYY-MM-DD.md`, written by wrap up. Claude reads today's and yesterday's when a session starts, so an unfinished thread carries over without you repeating it.

Each session is a block:

```
## Session 1

### Goal
(one line)

### Done
- (what was produced, and where it went)

### Decisions
- (what was decided and why)

### Open threads
- (what is unfinished, for next time)
```

When a second person joins, each person gets their own folder here (`memory/<first-name>/`) so two people working the same day never collide.
