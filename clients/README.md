# Clients

One folder per client, named in lowercase with hyphens (`future-proof`, `rapid-teams`). Each has a `MEMORY.md`: one page on what is live, what was agreed, and what to avoid. Claude reads it whenever a task names that client, and wrap up and "note that" keep it current.

To start: "Make a folder for each of these clients and ask me two questions about each." Copy `_template/MEMORY.md` for each one. Keep each memory under about 2,500 characters; when it is full, something leaves.
