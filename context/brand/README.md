# Brand

Drop here: your brand guidelines (PDF is fine), your logo files (the real ones, not a screenshot), and font files if you have them. If all you have is a website, say so when you run capture; it works as a fallback.

Capture reads this folder and writes `brand.md` next to it: colours, fonts, logo rules, how things should look. It also builds your Word and PowerPoint templates here. These stay in the brain, unlike your documents, because every skill that produces a file needs them.
