# Outbox

Finished files Claude made land here: a proposal as a Word file, a report, the output of a skill. They stay on this computer and never go to GitHub (the folder is in `.gitignore`).

When you send a file, move it to where it belongs (SharePoint, Drive, OneDrive, the client's folder) and tell Claude where it went if it should remember. Nothing in here is read at the start of a session.
